# Study Schedule Tracker

**Type:** Standalone web app (front-end)
**Estimated year:** ~2024
**Tech stack:** HTML, CSS, vanilla JavaScript

## What it does

A personal weekly study/exam planner (in Arabic) with two tables: one listing daily study tasks by subject with "Done / Not done / Clear" buttons per row, and a second table for tracking exam days.

## How it works

- Each task row has an `id`, and `markComplete()` / `markIncomplete()` / `clearMark()` toggle CSS classes on that specific cell to color it green or red.
- The tables were filled in by hand with real subjects and days as an actual personal study planner, not just a demo with placeholder data.

## What I learned

This one is a bit rough around the edges — the second table has some malformed HTML (unclosed tags) — and it's kept exactly as it was written, since the goal of this archive is to show real progress, not a polished-up version of the past. It's a useful marker of where my HTML structure discipline was at the time, especially compared to the more carefully structured markup in later projects like the cybersecurity awareness site.
